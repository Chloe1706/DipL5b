1. MediaPipe Setup

Installing and configuring the MediaPipe plugin for TouchDesigner. This involved downloading the plugin from the repository, placing the necessary files in the correct TouchDesigner directory, and verifying the install by running the example networks provided.

MediaPipe plugin directory structure

The plugin provides a CHOP component that outputs landmark data for detected hands — 21 keypoints per hand, each with x, y, z coordinates.

MediaPipe hand tracking CHOP output in TouchDesigner

2. Hand Tracking Data

Exploring which landmark channels are most useful for driving interaction. Index fingertip (landmark 8) and wrist (landmark 0) proved the most stable for mapping to output values.

CHOP channel view — landmark 8 x/y channels selected

Data was smoothed using a Lag CHOP to reduce jitter before being passed downstream. A Math CHOP remapped the raw 0–1 range to a more useful output scale.

TouchDesigner network — data smoothing chain

3. MIDI Output

Converting the processed hand position data to MIDI control change messages using the MIDI Out CHOP. This required mapping the smoothed x/y channel values to CC numbers 1 and 2 on channel 1.

MIDI Out CHOP — CC mapping settings

IAC Driver (Mac) was used as a virtual MIDI bus so TouchDesigner could send MIDI internally to Ableton without additional hardware.

Live MIDI output responding to hand position

4. Ableton Integration

Receiving the MIDI CC data in Ableton Live and mapping it to audio parameters — filter cutoff and reverb send. Hand height (y axis) controls the filter; horizontal position (x axis) controls reverb depth.

Ableton MIDI mapping view — CC1 and CC2 assigned

Testing the mapping with a looped audio clip confirmed a responsive, low-latency connection between hand movement and sound output.

5. Visual Feedback

Creating a visual layer in TouchDesigner that mirrors the hand interaction — particles and colour values driven by the same landmark data feeding the MIDI output. This gives users immediate visual confirmation that the system is tracking them.

Visual feedback — particles responding to hand tracking

TouchDesigner visual output network

6. Final Build

Combining the hand tracking, MIDI output and visual feedback into a single TouchDesigner project file. The final setup uses a laptop camera for tracking, outputs audio via Ableton, and projects visuals onto the tulip installation using a short-throw projector.
