Reflection

Mirror TOPs

Layering multiple Mirror transform operators is very effective in producing an interesting, psychedelic visual outcome. I ended up creating my own .tox file with an In/Out TOP as well as a series of Mirror TOPs with incrementing angles and pivot points. This will allow me to create an instant kaleidoscope effect in any network without needing to add and alter the parameters of the Mirror TOPs every time.

absTime Expression

By using a Transform operator and imputing absTime.seconds with different multipliers in the rotate X, Y and Z field I found I can create quite an interesting visual effect where the object rotates at varying speeds across X, Y and Z. This creates a less uniform and more dynamic motion compared to uniformed rotation. By offsetting the rotational speeds across axes, the motion resembles a more organic behaviour; reminding me of the rotation of planets which rotate on tilted axes at different rates.

Audio Isolation

I found that when using audio data to drive visuals, this was most effective when taking an isolated drum bass or kick. When using unfiltered audio, the effect was quite messy. However, by syncing with a consistent and sharp sound, so too were the visuals. In the Audio Analysis section I tried using the audio analyse component from the Touch Designer palette. This worked to an extent however, I've seen tutorials online where people build their own audio analysis and isolation network which appear to be more accurate. Moving into developing a final outcome for this project brief, I think I will investigate this option further.

Noise Operators

I love the versatility that Noise Operators have within Touch Designer. I think that finding a balance between uniform and organic qualities when creating visuals aligns with my own artistic interest. When looking at the work created by established individuals and collectives within the space such as the ones I wrote about for this project, it seems apparent that this methodology is commonly adopted; whether intentional or intuitive. I think it worth reiterating how Touch Designer poses the opportunity for a visual language where the duality of rigid, technical systems and organic forms can coexist. For these reasons, I am particularly drawn to Noise operators and the scope with which they can be applied to SOP and TOP operators.

Texture Operators

While experimenting with different techniques I found myself continuing to gravitate towards certain components.

For instance, once I'd learnt how to create a feedback loop with a Feedback and Cross TOP, I continued to use it across different works as, at varying levels of subtlety, it was particularly effective for visually translating motion. Likewise, I reached for the Bloom TOP across different works as I found that adding a glow, (one that appears brightest when it catches the brightest part of the input visuals), really enhanced the illusion of motion.

Compositing

Composite, Over and Lookup TOPs are all highly useful for overlaying visuals from separate networks in a variety of ways. Additionally the RGB key TOP is useful from a practicality standpoint as it adds a black background to visuals with very little effort. In some circumstances I used a Constant TOP with an Over TOP for the same purpose of adding a single colour background however this approach allowed me to choose other colours.

Ramp TOP

Finally, the Ramp TOP, sometimes in combination with Noise TOPs, was particularly useful for applying interesting colours and patterns to visuals. I made the discovery that by decreasing the number of periods in the period parameter window on the Ramp TOP to something small like 0.06, it would add parallel lines across the direction of the ramp type. When paired with a lookup TOP and some other visuals, this would add interesting, lined patterns.

Overall I would say I have formed a basic understanding of how to implement a range of operators to achieve different outcomes in Touch Designer however, I hope to expand on this more as I continue to work with the software.
